# emonad

The $EMO / Emonad memecoin site. Lives at [emonad.lol](https://emonad.lol).

## Pages

- **emo** — token landing page with live price ticker, lore, how to buy, games, and community links
- **memes** — emonad meme gallery, categorized and tagged, with copy / download / edit-with-meme-maker buttons
- **meme maker** — make memes on top of templates, stickers, and emojis; export as PNG or GIF
- **tarot** — emo tarot reader with all 22 Major Arcana; single-card, past/present/future, and 10-card Celtic Cross spreads
- **emo crush** — match-3 puzzle game with six emotion-themed gems (happy, sad, angry, shocked, love, cool)
- **flap emonad** — flappy bird-style game with on-chain leaderboard on Monad
- **profile** — public XP / levels profile page for each X-linked account
- **privacy** — privacy policy for the Emo Meme Picker browser extension
